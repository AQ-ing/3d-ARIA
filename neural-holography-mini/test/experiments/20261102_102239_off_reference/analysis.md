# Off 对齐实验结果

两组正常完成（returncode=0），均从 seed=42 随机初始化训练 1000 步。
共同条件：1920×1072 输入、1600×880 中央 ROI、homography 预处理、
vgg-low、Adam lr=1e-3、绿色通道。已查看两张最终重建图。

| 配置 | ROI 振幅 PSNR（匹配亮度） | 固定 sqrt(0.95) 亮度 PSNR |
| --- | ---: | ---: |
| current：现有 ASM + 训练时亮度匹配 | 31.128668 | 未记录 |
| reference：原项目 ASM + 固定强度系数训练 | 29.438739 | 29.393493 |

current 在同一 ROI、同一评价口径下高出 1.69 dB，振幅 MSE 约低 32.2%。
reference 的固定亮度与匹配亮度仅差 0.045 dB，因此其分数并非由评价时额外亮度调整明显抬高。
current 未记录固定亮度指标，不能据此宣称其绝对亮度还原优于 reference。

这说明现有网络和 ASM 在本轮条件下已能达到超过 31 dB 的 ROI 重建，
不支持“必须替换原项目 ASM 才能改善”的判断。两个实验同时改变了 ASM 与训练亮度处理，
不能单独认定哪一项导致 1.69 dB 差异。

与历史 960×640 全图实验相比，本轮同时改变了尺寸/孔径、目标裁剪、监督区域、
学习率与初始化，不能把数值差简单解释为净提升 6 dB，也不能分离各因素贡献。
两张图车体文字、窗框和枝条可辨；两组宏观视觉差异小于分数差，细纹理仍有伪影。
两组末段损失仍总体下降，当前排名只代表 1000 步预算下的结果。

建议优先保留 current 的网络/ASM/亮度匹配，采用本轮分辨率和 ROI 设置作为 off 基线。
如要归因，下一轮固定其余条件，做现有/原项目 ASM × 匹配/固定亮度的四格实验，
再单独检验 ROI 与全图监督。仍需同口径原项目基线才能断言达到其性能。
本次仅读取结果、查看图片并记录分析，没有启动训练或修改训练代码。
