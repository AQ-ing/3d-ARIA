# 六组实验分析

六组退出码均为 0，日志均包含最终指标和输出路径。已查看六张最终 PNG。
本次没有启动新训练或修改主目录。

| 模式 | MSE PSNR | vgg-low PSNR | MSE 高出 |
| --- | ---: | ---: | ---: |
| off | 24.87 | 23.77 | 1.10 dB |
| joint | 24.74 | 22.76 | 1.98 dB |
| controlnet-only | 23.94 | 22.29 | 1.66 dB |

PSNR 是亮度匹配后的线性振幅指标，960×640、绿色通道、单图单 seed。
off 为 800 步；ControlNet 从对应 off 权重出发再训练 1200 步。
joint_mse 比本轮 off_mse 低 0.13 dB，但与历史更充分训练的 off 25.52 dB 相比仍低 0.78 dB。
所以不能据此称两种模式已经达到相同上限。

视觉上 vgg-low 的部分文字、车身轮廓和人物边缘更鲜明；MSE 的这些区域偏软。
vgg-low 同时存在边缘变形/纹理伪影，因此低 PSNR 不能直接解读为所有细节均更差，
也不能把轮廓锐化等同于真实细节恢复。两类双深度输出均可见分区边缘不连续。

joint_mse 近/远分区为 26.16/22.82 dB；controlnet-only_mse 为 25.16/22.21 dB。
远景区域更难重建，但远景含大量细树枝，不能仅根据分区分数断言 0.22 m 传播本身有问题。
各组末段损失仍在下降且有波动，没有证据说明完全收敛。

建议下一轮优先保持同一个 MSE off 初始化，比较 MSE 与较小 VGG 权重，
以隔离初始化与损失的影响；同时增加非目标平面串扰/边界误差评价。
当前 ControlNet 两分支连同初始化一起变化，只能比较整套流程，不能归因于单一变量。
另应做统一输入和评价区域的原项目 ASM 基线；本轮未验证与原项目质量相当。
本文件仅记录分析与后续建议，没有安排或启动新实验。
